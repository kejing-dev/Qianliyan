专家怎么连上：两条路

浏览器只在 https 或 localhost 给麦克风。画面、笔迹、语音都只走这台头显自己开的服务，不经过任何云（手机热点也只是局域网）。

① 同一网络（https）· 真远程用这条

  1. 头显和电脑在同一个 Wi-Fi；公司 Wi-Fi 互相不通时，两边都连同一个手机热点
  2. 浏览器输入配对卡上的 30.16.255.24:8765 → 提示页 E6 → [继续]
  3. 浏览器「不安全」→「高级」→「继续前往」，输 PIN
证书第一次启动时生成并保存，同一台电脑只点一次；头显换了 IP 才会再提示。真机待验：Android 上能否生成这张证书、Chrome / Edge 接受后能否开麦；做不出来就只留 ②，配对卡换 S1u。

  1. 头显 USB 连电脑（头显要已允许这台电脑 USB 调试）
  2. 电脑运行 adb forward tcp:8765 tcp:8765

语音单开一条连接：画面一帧 60–90 KB，和 640 字节的语音包挤一条连接会被大帧堵住。用不压缩的 PCM：16 kHz 单声道 256 kbps，比画面小一个数量级，两边都不用加编码库；以后跨网再换 Opus。头显用 Android 通话录音（VOICE_COMMUNICATION）+ 回声消除，并明确把声音指定到头显扬声器（通话模式默认可能走听筒）；没有用 SpatialML 的麦克风算子，它是给模型喂音频的，不带通话回声消除。
